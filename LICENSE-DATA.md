# Upstream data licenses

The code in this repository is licensed under the terms in `LICENSE`.
The **data** it ingests is licensed separately by its publishers. Those
obligations travel with the data and are reproduced in the UI wherever the
data appears.

One row per upstream source. Add a row before ingesting anything new.
An unstated upstream license is a blocker, not a shrug.

| Source | URL | License | Required attribution | Date checked |
|---|---|---|---|---|
| _example_ | _https://..._ | _CC BY 4.0_ | _"Source: ..."_ | _YYYY-MM-DD_ |

## Notes

- If a source is unreachable and a mirror is used, list both rows and note
  the substitution in `knownGaps`.
- If a license is unclear, record what was found and where, and treat the
  source as unusable until resolved.
